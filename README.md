# Free developer website (GitHub Pages)

Use this folder as a free website for Play Store + AdMob `app-ads.txt`.

## Steps (about 10 minutes)

1. Create a **new public** GitHub repo named exactly:  
   `arhamgillani.github.io`

2. Upload **all files inside this `website/` folder** to that repo root  
   (so `app-ads.txt` is at the root, not inside a subfolder).

3. Wait 1–2 minutes, then open:
   - `https://YOUR_GITHUB_USERNAME.github.io/`
   - `https://YOUR_GITHUB_USERNAME.github.io/app-ads.txt`
   - `https://YOUR_GITHUB_USERNAME.github.io/privacy-policy.html`

4. **Google Play Console** → Store listing → Website:  
   `https://YOUR_GITHUB_USERNAME.github.io`  
   (no trailing slash; no `/website`)

5. Privacy policy URL:  
   `https://YOUR_GITHUB_USERNAME.github.io/privacy-policy.html`

6. **AdMob** → Apps → your app → check for `app-ads.txt` updates / verify again.

## Required line in app-ads.txt

```
google.com, pub-1522080377877119, DIRECT, f08c47fec0942fa0
```
